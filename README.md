# IA Iniciantes — iainiciantes.com.br

Site hospedado gratuitamente no **GitHub Pages**.

---

## 🚀 Como ativar o GitHub Pages

1. Faça upload de todos os arquivos no repositório GitHub
2. Vá em **Settings → Pages**
3. Em **Source**, selecione **GitHub Actions**
4. Salve — o site vai ao ar automaticamente

**URL gerada:** `https://SEU-USUARIO.github.io/SEU-REPOSITORIO`

---

## 🌐 Domínio próprio iainiciantes.com.br (gratuito)

1. No GitHub: **Settings → Pages → Custom domain**
2. Digite `iainiciantes.com.br` e salve
3. No Registro.br, configure os DNS:

```
Tipo A — aponte para:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

Tipo CNAME:
www → SEU-USUARIO.github.io
```

4. Marque **Enforce HTTPS** no GitHub Pages
